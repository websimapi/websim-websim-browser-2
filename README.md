# WebSim Browser

A dedicated desktop browser for WebSim.com, built with Electron.

## Features

- **Dedicated Browser**: Only allows navigation to WebSim.com
- **Cross-Platform**: Works on Windows, macOS, and Linux
- **Secure**: Blocks external navigation and new windows
- **Native Experience**: Feels like a native desktop application
- **Fast**: Optimized for WebSim performance

## Quick Start

### Automated Setup
